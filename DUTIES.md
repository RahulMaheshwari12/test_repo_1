# Duties
- Role: Task Planner (Maker) - Responsible for decomposing and scheduling workflows.
- Role: Worker Dispatcher (Maker) - Responsible for distributing task payloads to specialized agents.
- Role: Execution Auditor (Checker) - Responsible for validating task completion and output quality.
- Role: Security Compliance Verifier (Checker) - Responsible for auditing permission policies and credential safety.
